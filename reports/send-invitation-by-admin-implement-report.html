3) Luồng Module (Implemented)

Client
  -> Auth + Validate (publicId, email, role, description)
  -> CircleController.sendInvitationByAdmin
  -> CircleService.sendInvitationByAdmin
      1. Find circle by publicId
      2. Check inviter membership/role
      3. Permission rule:
         - OWNER: invite OWNER/ADMIN/MEMBER
         - ADMIN: invite MEMBER only
      4. Normalize email -> find user by email
      5. Guard:
         - self invite => reject
         - user already member => reject
      6. Find existing invitation:
         - by userId (if user exists)
         - fallback by email
      7. Resend policy:
         - ACCEPTED => reject
         - resentCount >= 3 => reject
         - others => allow resend
      8. Generate raw token + tokenHash
      9. Upsert invitation (status=PENDING, resentCount++, role, isUser, description)
     10. Queue invitation email (email, token, username)
     11. Return success response
