👥 Group / Community bonus

Nhóm chung sở thích. Thành viên có thể đăng bài, thảo luận trong nhóm. Admin nhóm quản lý thành viên và nội dung.

Proposed: Schema & API

Circle
Dự án đã có model Circle, CircleMember, CircleInvitation trong Prisma. Có thể mở rộng thành Group/Community.
Mở rộng
Thêm fields: description, coverImage, isPublic, memberCount. Thêm GroupPost (bài viết trong group).
API
POST /groups — tạo group
GET /groups/:id — chi tiết group
POST /groups/:id/join — tham gia
POST /groups/:id/posts — đăng bài trong group
GET /groups/:id/feed — feed group
GET /groups/discover — gợi ý group
Permission
3 role: OWNER (tạo nhóm), ADMIN (quản lý), MEMBER (đăng bài). Enum RoleMembership đã có trong Prisma.

🔴 Live Stream bonus

Phát sóng trực tiếp video. Viewer có thể comment realtime, gửi reaction. Tự động lưu replay sau khi kết thúc.

Proposed: Live Stream Architecture

Dùng Mux Live (đã có integration). Broadcaster push RTMP → Mux transcode → HLS playback. Chat overlay qua Pusher. Replay tự động lưu.

Mux
Dự án đã tích hợp Mux cho video upload. Mux Live Streaming thêm ~$0.025/phút stream. Tự động tạo replay asset khi stream kết thúc.
Webhook
Reuse MuxWebhookFlow đã có. Thêm event types: video.live_stream.active, video.live_stream.idle, video.asset.live_stream_completed.
Scale
1000 viewers = 1000 Pusher connections cho chat. Nếu cần scale hơn → dùng Pusher batch events hoặc poll API thay vì subscribe all.
Complexity
Live stream là feature phức tạp nhất. Khuyến nghị: chỉ làm nếu đã hoàn thành tất cả core features. Ưu tiên Story > Group > Live.
