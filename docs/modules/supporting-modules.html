Supporting modules

Các module dưới đây không có route prefix riêng nhưng quyết định auth, permission, quota, audit, report và side effect của các domain public. Khi trace một request, service thường đi qua một hoặc nhiều module trong danh sách này.

Pattern chính: public domain service → supporting service/repository → Prisma, Redis, queue hoặc provider. Không gọi trực tiếp các module này từ frontend.

Security và policy

access-control

Role, permission, role-permission, user-role và middleware checkRole. Admin router dựa vào ADMIN role; auth register gán USER role.

jwt

Generate và verify token pair. Payload chứa user id, status, roles và session id; auth middleware kết hợp JWT với Redis blacklist.

user-restriction

Lưu restriction có type và thời hạn. Circle dùng để chặn hành vi theo policy ngoài trạng thái ban toàn tài khoản.

anti-spam

Theo dõi hành động user trong ngày để service áp dụng giới hạn nghiệp vụ.

limit-action

Tạo giới hạn AI khi user vượt quota generate caption/image và lưu thời điểm reset.

transaction

TransactionService bọc Prisma transaction cho post/circle flow có nhiều write phụ thuộc nhau.
