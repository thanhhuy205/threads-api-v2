Architecture · Data Model

Mô hình dữ liệu

Trang này mô tả cách dữ liệu được tổ chức trong database. Hiểu data model là hiểu hệ thống xem điều gì là quan trọng.

Sơ đồ ERD

Sơ đồ dưới gom bảng theo cụm nghiệp vụ để người đọc thấy quan hệ chính trước.

ERD rút gọn theo cụm. Bảng chi tiết bên dưới liệt kê entity chính.

Vòng đời dữ liệu

1

User/register tạo user + role + refresh token.

2

User tạo post/circle/message/report/quest log qua module tương ứng.

3

Worker cập nhật dữ liệu phụ như search index, quality log, notification và flags.

4

Delete thường là soft delete ở post; nhiều bảng khác chưa có soft delete rõ ràng.
