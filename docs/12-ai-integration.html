① AI Content Moderation bắt buộc

Bài/comment mới → queue → AI worker kiểm tra → safe (pass) / suspicious (admin review) / toxic (auto-hide). Không block user.

#TaskChi tiết triển khaiStatus
01
BullMQ: moderation queue
Tạo queue ai-moderation. Producer: gọi trong PostService.post() và PostService.reply() sau khi tạo bài.todo
02
Worker: OpenAI Moderation
Gọi POST /v1/moderations (free API). Parse response: categories (hate, violence, sexual...) + category_scores.todo
03
Decision logic
Score <0.5 → pass. 0.5–0.9 → flag cho admin. >0.9 → auto-hide + INSERT Report(type=AI_FLAGGED). Thresholds cấu hình qua env.todo
04
Fallback nếu API fail
OpenAI timeout/error → retry 3 lần → nếu vẫn fail → pass (không block user) + log warning cho admin review sau.todo

③④ Smart Reply & Recommendation

AI Smart Reply

KHUYẾN KHÍCH

Khi nhận tin nhắn chat, gợi ý 3 câu trả lời nhanh dựa trên context cuộc hội thoại. User nhấn 1 cái để reply ngay.

API: POST /ai/smart-reply
Input: 10 tin nhắn gần nhất
LLM: GPT-4o-mini (nhanh, rẻ)
Output: 3 suggested replies
Latency target: <2s

AI Recommendation

KHUYẾN KHÍCH

Gợi ý kết bạn và bài viết dựa trên sở thích & tương tác. Collaborative filtering + content-based.

API: GET /ai/recommend?type=user|post
Vector: Pinecone (user + post embeddings)
Signal: likes, follows, topics, interactions
Batch: Cron job mỗi 6h tính embedding
Cache: Redis sorted set, TTL 1h

Potential Issues

Latency
OpenAI API: 1–3s. Moderation chạy async (queue) nên OK. Caption/SmartReply chạy sync → cần loading UI. Hoặc dùng streaming (SSE) cho UX tốt hơn.
Cost
GPT-4o-mini rẻ (~$0.15/1M input tokens). Nhưng nếu mọi bài đều gọi caption → tốn. Chỉ gọi khi user bấm "Gợi ý AI", không auto-generate.
Rate limit
OpenAI rate limit per org. Cần: server-side rate limit per user (5 caption requests/giờ), retry with exponential backoff, graceful degradation.
Prompt inject
User có thể chèn prompt injection trong nội dung bài. Moderation API resistant, nhưng caption/reply cần sanitize input + system prompt guard.
Fallback
Nếu OpenAI down → feature AI degrade gracefully. Moderation: pass all. Caption: "Không thể gợi ý lúc này". Không crash toàn app.
