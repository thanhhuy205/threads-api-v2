Potential Issues

LIKE chậm
LIKE '%keyword%' không dùng index, full table scan. OK cho <50K rows. Cần FULLTEXT index hoặc ngram parser cho scale.
Tiếng Việt
MySQL FULLTEXT mặc định dùng ngram parser cho CJK/Vietnamese. Cấu hình ngram_token_size=2 trong my.cnf. Pinecone xử lý tốt hơn nhờ multilingual embedding model.
Injection
Query q cần sanitize: trim, remove SQL special chars, escape %_ cho LIKE. Zod validate min 1 char, max 100 char.
Rate limit
Search là endpoint tốn tài nguyên. Rate limit 30 req/phút per user. Autocomplete debounce 300ms phía FE.
