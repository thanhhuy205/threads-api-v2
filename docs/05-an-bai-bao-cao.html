User Perspective

Ẩn bài
Thấy bài viết không phù hợp trên feed → nhấn menu "⋯" → chọn "Ẩn bài" → bài biến mất khỏi feed cá nhân. Chỉ ẩn với mình, người khác vẫn thấy bài. Không thể ẩn bài của chính mình.
Báo cáo
Thấy bài vi phạm → nhấn "Báo cáo" → chọn lý do (spam, harassment, hate speech...) → gửi. Hệ thống ghi nhận và đưa vào hàng đợi duyệt admin.

Hide Post Flow

Ẩn bài = toggle isGhost. Nhấn lần đầu → ẩn, nhấn lại → hiện. Không cho phép ẩn bài của chính mình.

API Detail

# API / Tính năng Mô tả nghiệp vụ Trạng thái
01
POST /:publicId/hide
Ẩn bài
 Toggle isGhost trên bài viết. Không cho ẩn bài của mình. Ẩn lần 2 = hiện lại. Hiện tại ẩn trên tất cả feed (cần sửa thành ẩn chỉ với user đó). done
02
POST /:publicId/report
Báo cáo vi phạm
 Nhận reason (lý do báo cáo) từ body. Hiện tại chỉ là stub (no-op), chưa lưu vào DB hay tạo review queue. stub
03
Ghost → per-user
Ẩn theo từng người
 Hiện tại isGhost ẩn bài cho tất cả. Cần chuyển sang bảng riêng HiddenPost(userId, postId) để mỗi user ẩn riêng. todo
04
Report storage
Lưu báo cáo vào DB
 Tạo bảng Report(userId, postId, reason, status, createdAt). Lưu mỗi báo cáo, status = PENDING/REVIEWED/DISMISSED. todo
05
Admin review queue
Duyệt báo cáo
 Trang admin liệt kê các báo cáo PENDING, cho phép admin xem bài vi phạm và quyết định: xóa bài / cảnh cáo user / bỏ qua. todo

Design Notes

isGhost
Hiện tại isGhost là field trên bảng Post — ẩn cho tất cả mọi người. Cần chuyển sang bảng riêng HiddenPost để mỗi user ẩn riêng cho mình.
Report
Validate schema đã có (reportSchema yêu cầu reason là string). Chỉ cần thêm DB layer + admin UI.
AI tie-in
Khi implement AI Content Moderation, có thể auto-flag bài có report count cao hoặc confidence score cao → tự ẩn, đợi admin duyệt.
