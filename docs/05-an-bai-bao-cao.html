User Perspective

Ẩn bài
User có thể ẩn bài khỏi feed bằng route /:publicId/hide. Đây là toggle trực tiếp cờ isGhost trên bài viết (global).
Báo cáo
User gửi reason + type vào /:publicId/report. Hệ thống tạo report, lưu người report, target type, target id.
Tự động
Với report post/circle, worker AI đánh giá độ tin cậy. Nếu confidence >= 0.96 thì bài sẽ bị isHidden=true và bị loại khỏi list/feed.

Report Flow (Implemented)

Report POST/CIRCLE sẽ được AI đánh giá bất đồng bộ. USER report chỉ tạo record PENDING, chưa có auto-hide.

Design Notes

Target mapping
type=user dùng :publicId như user id. type=post/circle dùng publicId của bài viết làm target id.
Safety rule
Chặn self-report cho cả user target và post target. Duplicate report được phép tạo nhiều bản ghi độc lập.
Visibility
Bài isHidden=true không hiện trong list/feed, nhưng vẫn đọc được qua GET /posts/:publicId để phục vụ moderation và audit.
