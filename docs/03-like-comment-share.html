User Perspective

Like
Nhấn nút ❤️ trên bài viết → tim đổi màu, số like tăng lên tức thì. Nhấn lại → unlike. Tất cả xảy ra gần như ngay lập tức nhờ Redis.
Comment
Nhấn "Trả lời" → mở giao diện viết reply → nhập nội dung (hỗ trợ text + media + @mention) → gửi. Reply xuất hiện dưới bài gốc. Có thể reply lại 1 reply (nested 1 cấp).
Repost
Nhấn nút "Chia sẻ" → chọn "Repost" → bài gốc xuất hiện trên trang cá nhân người dùng, giữ nguyên nội dung.
Quote
Nhấn "Chia sẻ" → chọn "Trích dẫn" → viết thêm lời bình → đăng. Bài viết mới chứa bài gốc bên trong kèm bình luận của mình.

Like Flow (Redis-based)

Like/Unlike dùng Redis SET để đảm bảo idempotent. Worker background sẽ flush queue về MySQL định kỳ.

# API / Tính năng Mô tả nghiệp vụ Trạng thái

POST /:publicId/like
Like / Unlike
 Toggle like: isLiked=true → thêm vào Redis SET + tăng counter, push queue. isLiked=false → xóa khỏi SET + giảm counter, push queue khác. Đảm bảo idempotent (like 2 lần = 1 like). done
02
POST /:publicId/reply
Comment (Reply)
 Tạo bài mới loại REPLY gắn với parentPublicId. Hỗ trợ đầy đủ text + media + @mention. Transaction + attachPostMeta. Nested 1 cấp (reply → reply). done
03
POST /:publicId/repost
Chia sẻ nguyên bài
 Tạo bài loại REPOST link tới bài gốc bằng originPublicId + originPostId. Không cần transaction vì không có meta phụ. done
04
POST /:publicId/quote
Trích dẫn + bình luận
 Tạo bài loại QUOTE. Giống reply nhưng link tới bài gốc thay vì parent. Có transaction, mention, topic. User viết thêm nội dung kèm bài gốc. done

Design Notes

Redis Like
Like dùng Redis SET (SADD/SREM) vì cần idempotent + real-time. Worker background flush về DB theo batch, giảm tải write MySQL.
Comment = Reply
Trong hệ thống, "comment" thực chất là một bài viết loại REPLY có parentPublicId trỏ về bài gốc. Dùng chung bảng Post.
Repost vs Quote
Repost = chia sẻ nguyên xi, không có transaction/meta. Quote = tạo bài mới chứa bài gốc bên trong, có đầy đủ mention/topic/transaction.
Nested 1 cấp
Reply một reply tạo thread 2 cấp. Cần enforce logic để không cho nested sâu hơn (tránh phức tạp UI + query).
