Dự án này làm gì?

Threads API v2 là backend cho một mạng xã hội kiểu Threads: người dùng đăng ký, đăng nhập, đăng bài, reply, quote, follow, gửi friend request, chat realtime và nhận notification.

Điểm riêng của hệ thống là circle: một cộng đồng nhỏ có thành viên, quyền quản trị, bài viết riêng và cơ chế HP/EXP. Khi thành viên đăng bài trong circle, hệ thống lưu bài và worker chấm chất lượng bằng AI.

Những tác vụ nặng như gửi email, index search, tạo embedding, sync like và gom notification được đưa ra worker để request chính trả nhanh hơn.

Sơ đồ tổng thể hệ thống

Request đi từ client vào Express API. API đọc/ghi MySQL qua Prisma, dùng Redis cho cache/queue, và đẩy tác vụ nặng sang worker. Worker mới gọi AI, search, email, storage hoặc realtime provider.

Màu cam là API server, màu xanh là worker xử lý phần nặng sau response.

Luồng chính của hệ thống

1

User đăng ký hoặc login để nhận access token và refresh token.

2

User tạo post hoặc circle post; server validate payload rồi ghi DB.

3

Side effects như email, Bloom, Elastic, Pinecone, like sync, notification được worker xử lý.

4

Client đọc feed/search/notification/chat qua API và realtime Pusher.

PineconeVector database để tìm bài gần nghĩa.
ElasticsearchSearch engine cho text search.
PusherRealtime service gửi event về client.
Cloudflare R2Object storage S3-compatible để lưu ảnh.
