API reference

Swagger + HTML

Swagger tại /api/v1/docs là reference có thể gọi thử; các trang HTML bổ sung bối cảnh nghiệp vụ và side effect.

HTTP groups đang được mount

Base path /api/v1. Mọi group đi qua global rate limiter; auth tùy vị trí middleware trong route file.

current route catalog authuser postcircle adminmessage notificationsearch uploadwebhooks aiquest topicpusher museumhealth
  1. Client gọi /api/v1/*.
  2. Helmet, CORS, compression, body parser, logger và response helper chạy.
  3. Global rate limiter chạy trước module router.
  4. Route-specific auth và Zod validation chạy theo khai báo.
  5. Controller trả envelope success/data/pagination.
