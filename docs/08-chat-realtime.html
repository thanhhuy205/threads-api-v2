Potential Issues

Message order
Tin nhắn gửi đồng thời có thể đến không đúng thứ tự. Giải pháp: server timestamp + client sort theo createdAt. Optimistic UI hiện tin ngay, reorder khi server confirm.
Offline
User B offline khi A gửi tin. Cần: 1) Lưu DB trước, 2) Pusher deliver khi B online, 3) Khi B mở app → load unread từ API. Push notification (FCM/APNs) cho mobile.
Scale
Pusher (Soketi) có limit connections. Nếu >10K concurrent cần horizontal scale Soketi hoặc chuyển sang Socket.IO cluster (Redis adapter).
File/Image
Gửi ảnh/file: upload qua Upload module trước (giống Post media), nhận URL, gửi message type=IMAGE/FILE. Không gửi base64 qua WebSocket.
Encryption
E2E encryption (tùy chọn): nếu cần, dùng Signal Protocol. Phức tạp, khuyến nghị Phase 3+. Phase 1 dùng TLS đủ an toàn.
