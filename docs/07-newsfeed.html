Potential Issues

N+1
Enrich isLiked/isQuoted hiện dùng sub-select trong Prisma findMany. Khi feed lớn (>1M bài), cần chuyển sang Redis lookup hoặc denormalize.
Cold start
User mới chưa follow ai → feed FOLLOWING trống. Giải pháp: fallback sang FOR_YOU, hoặc suggest follow list (onboarding).
Fan-out
Hiện tại dùng fan-out-on-read (query lúc đọc). Khi scale, cần fan-out-on-write (pre-compute feed khi có bài mới) với BullMQ.
Stale cache
Cache feed 60s nhưng bài mới xuất hiện chậm 60s. Trade-off chấp nhận được. Hoặc invalidate cache qua Pusher event khi bài mới được tạo.
