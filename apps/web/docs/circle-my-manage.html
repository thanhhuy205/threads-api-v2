Circle · my manage page

My Circle Manage QA spec

Spec riêng cho route /[locale]/circle/manage. Page này chỉ kiểm thử danh sách Circle mà user đang quản lý/owner, không phải dashboard quản trị của từng Circle.

01

Source Map

Page

CircleManagePageClient cho owner overview list.

API

GET /circle/me/owner-circle trả danh sách group user quản lý/owner.

Next Route

Bấm một group quản lý đi tới /circle/:publicId/manage, nơi có permission gate riêng.

02

Functional Scope

Owner/Managed List

  • Hiển thị những Circle user đang quản lý hoặc owner theo backend.
  • Empty state rõ ràng khi user chưa quản lý group nào.
  • Pagination/load more không duplicate dữ liệu.

Not Sidebar Mock

  • Danh sách này khác với mock Groups you've joined ở Circle List sidebar.
  • Không dùng sidebar mock để verify dữ liệu quản lý thật.

Permission Continuity

  • Nếu user mất quyền quản lý sau khi list đã load, route /circle/:publicId/manage vẫn phải bị chặn.
  • Manage detail cần isAdmin=true và manage_super.
