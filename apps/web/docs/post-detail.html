Post Detail QA spec

Trang chi tiết bài viết cần kiểm thử tương tác giống post card bình thường, danh sách reply/comment bên dưới, reply lồng nhau theo chuỗi thread sâu, bộ lọc hàng đầu, nút xem hoạt động và nút xem bài viết tương tự.

Expected Behavior

  • Post chính dùng PostCard mode="detail", vẫn like/unlike, comment/reply, repost, quote, share như trên feed.
  • Reply/comment bên dưới dùng PostCard mode="comment"; click vào reply sẽ đi tới detail của reply đó.
  • Menu ba chấm vẫn có save/hide/report/copy link theo quyền đăng nhập.
  • Nếu chưa đăng nhập, các action cần auth phải mở login modal.
03

Nested Reply Thread

Reply Depth

  • QA cần tạo chuỗi reply lồng nhau càng sâu càng tốt để kiểm tra route detail của từng reply.
  • Mỗi reply con vẫn có like, reply, repost/quote, share và menu theo cùng rule của bài viết.
  • Danh sách reply đang phân trang bằng infinite query; scroll cuối list phải fetch trang tiếp theo nếu hasNextPage.

Top Filter And Activity

  • Nút Hàng đầu hiện mới render UI, chưa có menu lọc hoặc handler đổi sort.
  • Nút Xem hoạt động hiện mới render UI, chưa có handler mở activity panel.
  • QA cần đánh dấu hai nút này là chưa dùng được cho đến khi có logic triển khai.

Similar Posts

Button

  • Nút Tương tự nằm ngay dưới post chính, mở modal Bài viết tương tự.
  • Khi mở lần đầu, gọi POST /posts/:publicId/similar với content và danh sách topic.
  • Kết quả điều hướng sang /[username]/post/[publicId] khi bấm một bài tương tự.

Seed Data Note

  • API trả tối đa 5 bài viết tương tự.
  • Hiện môi trường đang chạy seed nên có thể không tìm thấy bài tương tự.
  • Khi thêm đủ nhiều dữ liệu mới và nội dung/topic đủ gần nhau, query có thể trả về danh sách bài tương tự.
