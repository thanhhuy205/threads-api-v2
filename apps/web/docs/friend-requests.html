Friend Requests QA spec

Route /[locale]/friend-requests. Kiểm thử yêu cầu kết bạn nhận được, chấp nhận/từ chối và sync sang friends/messages.

DoneReceived requests list, pending detection và infinite pagination.
APIGET /me/friend-requests/received, accept/reject mutations.
SyncAccept cần cập nhật friends, friend request count và message eligibility.
ActionsMỗi card có profile link, Accept và Reject khi status pending.
