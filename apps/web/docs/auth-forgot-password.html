Forgot Password QA spec

Page gửi email reset mật khẩu. Chức năng hiện tại đã hoàn thành: validate email, kiểm tra email có tồn tại, gọi API forgot password và gửi origin header cho backend tạo link.

03

Validation

Client validation

  • email: required string và phải là email hợp lệ.
  • Lỗi hiển thị qua FormMessageI18n.

BFF/server validation

  • email: trim, email hợp lệ, tối đa 255 ký tự.
  • Nếu body invalid, BFF trả validation response trước khi forward backend.

Existence check

  • Client gọi validateEmail(values) trước.
  • Nếu available === false, email tồn tại và mới gọi forgot password.
  • Nếu available === true, hiển thị auth.emailNotFound.
