Profile · personal account

Profile QA spec

Profile cá nhân cho phép sửa thông tin, đặt trạng thái riêng tư/công khai, xác thực email và đăng bài. Có thể xem replies và reposts; media tab hiện chưa render dữ liệu media. Bài viết cá nhân có thể lưu, copy link và xóa.

02

Profile UI

Expected Behavior

  • Header hiển thị name, username, avatar, bio, website và verified badge nếu có verifiedAt.
  • Nếu email chưa verify, hiển thị nút Verify email; bấm gửi lại email xác thực.
  • Nút Edit profile mở modal cài đặt profile.
  • Tab gồm threads, replies, media files và repost.
03

Edit Profile

Personal Info

  • Sửa name, bio, link label, website và avatar preview.
  • Username chỉ hiển thị, không sửa trong modal hiện tại.
  • Submit gọi PATCH /me/profile thông qua useUpdateProfileMutation.

Privacy

  • Switch isPrivate đổi profile giữa private và public.
  • QA cần kiểm tra public profile của user khác có phản ánh đúng trạng thái private/public sau khi lưu.

Email Verification

  • User chưa verify thấy nút verify trong profile header.
  • Bấm verify gọi resend verify email và hiện toast thành công/thất bại.
  • Verify token flow nằm ở /[locale]/verify-email.
04

Tabs And Posts

Threads

  • Tab chính hiển thị bài viết cá nhân và setup profile card nếu profile chưa hoàn tất.
  • User có thể post từ profile bằng composer/new post entry point.

Replies And Reposts

  • /profile/replies xem các reply của user.
  • /profile/repost xem các bài repost/quote của user.
  • Các list dùng infinite query và skeleton khi loading.

Media

  • /profile/media hiện có route và tab nhưng component ProfileMedia đang render rỗng.
  • QA ghi rõ media file đang loading/chưa xem được ở thời điểm hiện tại.

Personal Post Menu

  • Bài viết của chính user dùng MenuMe.
  • Có save/unsave, copy link và delete với confirm modal.
  • Các item pin/hide stats/control options đang comment, chưa dùng.
