Create Circle Post QA spec

Spec riêng cho route /[locale]/circle/[publicId]/create. Page này kiểm thử đăng bài trong Circle, editor làm đẹp nội dung, tạo ảnh AI, quota AI và quality log ảnh hưởng HP/EXP.

01

Source Map

Page

circle/[publicId]/create/page.tsx, CirclePostForm, CircleLexicalEditor.

Post API

POST /circle/:publicId/posts với content, contentJson, mediaUrls.

AI APIs

POST /circle-ai/generate-response để beautify; POST /ai/generate-image để tạo ảnh.

02

Functional Scope

Post Composer

  • Chỉ member đã join và Circle chưa dead nên vào được flow tạo bài.
  • Không cho submit khi content rỗng và không có media.
  • Submit thành công quay về detail và bài mới xuất hiện trong feed sau refetch.

Beautify Content

  • Toolbar editor có action AI beautify gọi /circle-ai/generate-response.
  • Phải giữ được nội dung người dùng khi API lỗi/time out.
  • Quota nghiệp vụ: tối đa 5 lần/account; QA cần xác nhận lỗi backend khi vượt quota.

Generate Images

  • Tạo ảnh AI cần content làm prompt và nhận generationId.
  • Nghe realtime leonardo-generation-complete trên channel generation.
  • Realtime hoàn tất thì ảnh xuất hiện trong editor; khi realtime lỗi hoặc quá lâu, UI giữ trạng thái chờ/lỗi nhẹ nhàng.

Quality Log

  • Backend trả qualityLog gồm score, label, hpDelta, expDelta, reason/confidence.
  • Điểm tốt tăng HP/EXP; toxic/spam hoặc điểm thấp có thể giảm HP.
  • Manage Post Quality Logs phải nhìn thấy log của bài vừa tạo nếu backend trả data.
