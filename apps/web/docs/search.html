Trang Search ở /[locale]/search cần có mock UI mẫu khi chưa nhập để không trống vắng. Khi nhập query, một lần nhập phải tìm đồng thời cả bài viết và người dùng; người dùng trong kết quả có thể được follow ngay trên trang Search.

Expected Behavior

  • Khi q rỗng, hiển thị mock discovery gồm chip xu hướng, danh sách chủ đề đang thịnh hành và gợi ý follow.
  • Mock UI chỉ là trạng thái mẫu để trang không trống, không cần gọi API search.
  • Các nút follow trong mock đổi trạng thái trực quan để QA biết vị trí hành động follow.
03

Single Query Dual Results

Input behavior

  • User nhập vào ô search, query được debounce rồi cập nhật URL ?q=....
  • QA yêu cầu một lần nhập phải fetch cả /search/posts và /search/username, không bắt user đổi tab mới gọi API người dùng.
  • Kết quả nên chia thành hai khối trên cùng trang: Bài viết và Người dùng.

Posts result

  • Render bằng PostCard, click post đi tới /[username]/post/[publicId] nếu có username.
  • Hỗ trợ loading skeleton, empty state và pagination cho post qua cursor.

Profiles result

  • Hiển thị avatar, username, verified, name/bio nếu có.
  • Có nút Theo dõi ngay trên từng user result; sau click đổi thành Đang theo dõi.
  • Nếu chưa đăng nhập, follow phải mở modal login giống các action cần auth.
