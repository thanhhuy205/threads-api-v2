03

Validation

Client validation

  • username: required string, tối thiểu 6 ký tự, regex ^[a-zA-Z0-9_-]+$.
  • email: email hợp lệ.
  • password: required string, tối thiểu 8 ký tự.
  • confirmPassword: phải bằng password.
  • Nếu username/email không available, set manual error USERNAME_EXISTS/EMAIL_EXISTS.

BFF/server validation

  • username: trim, 3-32 ký tự, regex ^[a-zA-Z0-9._-]{3,32}$.
  • email: trim, email hợp lệ, tối đa 255 ký tự.
  • password và confirmPassword: 6-128 ký tự.
  • confirmPassword phải khớp password.
