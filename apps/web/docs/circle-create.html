Circle · create page

Create Circle QA spec

Spec riêng cho route /[locale]/circle/create. Page này chỉ kiểm thử form tạo community/group mới và trạng thái sau khi tạo.

01

Source Map

Page

circle/create/page-client.tsx, sidebar form và preview create Circle.

API

POST /circle với name, description, visibility, avatarEmoji.

After Create

Sau khi tạo thành công, Circle mới phải xuất hiện ở list phù hợp và owner list/manage list.

02

Functional Scope

Form Fields

  • Nhập tên, mô tả, visibility public/private và avatar emoji nếu UI hỗ trợ.
  • Preview bên phải phản ánh dữ liệu đang nhập.
  • Submit disabled hoặc báo lỗi khi thiếu name/description theo rule backend.

Create Result

  • Gọi POST /circle, hiển thị loading và toast/error rõ ràng.
  • Không tạo duplicate khi double click submit.
  • Private Circle mới phải có rule join/request đúng khi user khác xem.

Not In This Page

  • Invite member thuộc manage page, không test như chức năng chính của create page.
  • Đăng bài trong Circle thuộc /circle/:publicId/create.
  • HP/burn/level-up thuộc Circle Detail.
