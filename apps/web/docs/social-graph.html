02

Followers Card

Expected Behavior

  • Page /[locale]/follower hiển thị danh sách người đang theo dõi user hiện tại.
  • Bấm avatar/name đi tới profile công khai của người đó.
  • Nếu chưa follow lại, nút hiển thị Theo dõi; bấm sẽ gọi follow API và đổi sang Đang theo dõi.
  • Nếu đã follow, nút Đang theo dõi phải cho hủy theo dõi như hành vi follow/unfollow bình thường.
  • Danh sách dùng infinite scroll và phải load thêm khi còn hasNextPage.
03

Friend Request Cards

Yêu cầu kết bạn

  • Route: /[locale]/friend-requests.
  • Data: GET /me/friend-requests/received.
  • Mỗi card hiển thị người gửi, link tới profile, nút Đồng ý kết bạn và Từ chối kết bạn.
  • Accept gọi /me/friend-requests/:username/accept; reject gọi handler với { isAccept: false }.

Yêu cầu đã gửi

  • Route: /[locale]/send-request.
  • Data: GET /me/friend-requests/sent.
  • QA spec mong muốn card này cũng có đủ hai action: Chấp nhận và Từ chối/Huỷ theo trạng thái backend trả về.
  • Implementation hiện tại mới có nút Huỷ lời mời kết bạn cho request pending, nên cần bổ sung/verify action chấp nhận nếu backend hỗ trợ.
04

State Rules

Pending

  • Request pending phải có action button, disabled trong lúc mutation đang chạy.
  • Không được gửi nhiều mutation trùng khi double click.

Accepted

  • Request accepted hiển thị trạng thái đã kết bạn, không còn nút accept/reject.
  • Follower/following state nên được refetch hoặc cập nhật optimistic sau khi accept.

Rejected Or Canceled

  • Request rejected/canceled hiển thị trạng thái đã hủy hoặc bị từ chối.
  • Không để item pending cũ còn action sai trạng thái sau khi API thành công.
