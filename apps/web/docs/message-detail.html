Message Detail QA spec

Route /[locale]/messages/[conversationId]. Page này kiểm thử gửi text, icon/emoji, realtime Soketi/Pusher, trạng thái checkmark và điều kiện chỉ nhắn tin khi hai người còn là bạn bè.

Message Status

...
Pending

Vừa bấm gửi, bubble xuất hiện ngay với trạng thái chờ.

✓
Received

Recipient/server nhận message thì sender thấy một checkmark.

✓✓
Seen / Read

Khi người nhận đã xem, sender thấy hai checkmarks.

Realtime Flow

  1. Người gửi nhập text hoặc chọn emoji/icon.
  2. POST /message-groups/:publicId/messages tạo message với clientMessageId.
  3. Soketi/Pusher đẩy message mới vào room tức thì, không cần reload.
  4. PATCH /message-groups/:publicId/messages/:messagePublicId/status cập nhật trạng thái đã nhận/đã xem.
