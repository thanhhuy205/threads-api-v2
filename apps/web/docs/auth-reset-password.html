Reset Password QA spec

Page đặt lại mật khẩu bằng token từ email. Chức năng hiện tại đã hoàn thành: validate token server-side trước khi render form, validate email/password/confirm password và redirect về login sau khi submit.

03

Validation

Token gate

  • Nếu query không có token: redirect sang forgot password.
  • Nếu token invalid: render component lỗi RestPasswordFound.
  • Token được validate qua /auth/reset-password/validate?token=....

Client validation

  • token: required.
  • email: email hợp lệ.
  • password: required string, tối thiểu 8 ký tự.
  • confirmPassword: phải khớp password.

BFF/server validation

  • token: tối thiểu 1 ký tự.
  • email: trim, email hợp lệ, tối đa 255 ký tự.
  • password: 8-128 ký tự.
  • confirmPassword: phải khớp password.
04

Route map

01 · Link

User mở /[locale]/reset-password?token=....

02 · Gate

Server page đọc token từ query.

03 · Validate

Gọi validateResetPasswordToken(token).

04 · Form

Nếu hợp lệ, render email + password + confirm.

05 · Submit

POST /auth/reset-password.

06 · Done

Toast success/error, sau đó router.replace('/[locale]/login').
