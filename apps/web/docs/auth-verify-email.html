Public behavior

Route

/[locale]/verify-email?token=... không yêu cầu session. Server gọi backend với auth: false.

Missing token

Nếu không có token hoặc token rỗng, redirect về /[locale]/login.

Token expired UI

Client component tồn tại để hiển thị màn hình token expired/error với nút về login và home, nhưng normal server branch đang redirect khi verify thành công/thất bại.

04

Route map details

Verify API call

  • verifyEmailToken(token) POST /auth/verify-email.
  • Body là { token }.
  • Nếu response không ok: return false.
  • Nếu JSON parse được và success !== false: coi là verified.

Home toast

  • ?verified=1: show auth.verifySuccess rồi xóa query khỏi URL.
  • ?error=verify-failed: show auth.verifyFailed rồi xóa query khỏi URL.

Profile CTA

  • Nếu user.verifiedAt có giá trị: chỉ hiện Edit Profile full width.
  • Nếu chưa verified: hiện Edit Profile và Verify Email cạnh nhau.
  • Resend success: toast auth.verifyEmailSuccess; error: toast message từ API hoặc auth.verifyEmailFailed.
