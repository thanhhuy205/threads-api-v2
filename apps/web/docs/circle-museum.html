Circle Museum QA spec

Spec riêng cho route /[locale]/circle/museum. Page này hiện được xem là prototype/UI mock, không dùng để kết luận contract backend museum.

UI/mock scope
01

Functional Scope

Standalone Museum

  • Kiểm thử layout, empty state, card/preview và responsive.
  • Dữ liệu hiện dựa vào mock/local data, không verify bằng API museum.
  • Không dùng page này để kết luận số lượng media/bài lưu niệm thật.

Detail Museum Tab

  • Trong Circle Detail, tab Museum dùng recent media từ post feed.
  • Member đã join mới thấy tab museum đầy đủ.
  • Circle chưa join/private bị khóa theo rule detail page.

Backend Gap

  • Handoff có nhắc endpoint /api/v1/museum, nhưng frontend hiện chưa wired client rõ ràng.
  • Nếu product yêu cầu dữ liệu thật, cần thêm client hoặc test backend riêng.
