Private Profile QA spec

Route /[locale]/profile. Kiểm thử hồ sơ cá nhân, chỉnh sửa thông tin, verify email, privacy và bài viết của chính mình.

DoneShell profile, tabs, counters, edit profile modal và verify email button đã có.
APIPATCH /me/profile, resend verify email, load my posts.
PartialMedia tab có route nhưng component đang rỗng.
ReviewSave/copy/delete post cá nhân nằm trong menu post, cần test theo từng card.

Functional Cards

Profile editor

  • Name, bio, website/label website, avatar và privacy public/private.
  • Preview data sau save không cần reload trang.

Verification

  • User chưa verified thấy nút gửi lại email xác thực.
  • User verified chỉ thấy edit profile.

Personal posts

  • Load threads của chính mình, composer/new post entry point.
  • Post menu có save/unsave, copy link và delete.
